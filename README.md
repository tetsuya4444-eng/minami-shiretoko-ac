# 南知床山岳会 町ホームページ

北海道中標津町を拠点とする南知床山岳会の公式Webサイト。

## 構成

- `index.html` - メインページ（シングルページ構成）
- `css/style.css` - スタイルシート
- `js/main.js` - JavaScript
- `images/` - 画像素材

## 技術スタック

- HTML / CSS / JavaScript（フレームワークなし）
- 静的サイト

## ローカル確認

```bash
python3 -m http.server 8080
```
http://localhost:8080 でプレビュー可能。
